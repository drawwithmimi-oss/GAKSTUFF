# 🚀 Quick Start - Import Your Sheets in 5 Minutes!

## What You Have

4 CSV files ready to import:
- ✅ `1_Bookings.csv` - 11 sample bookings
- ✅ `2_Locations.csv` - Holly Street & D Street/DuPont
- ✅ `3_Program_Types.csv` - ECE, ASAP, Music, Adult, Off-site
- ✅ `4_Users.csv` - Staff members (UPDATE EMAILS!)

## 5-Minute Setup

### Step 1: Create Google Sheet (1 min)
1. Go to **[sheets.google.com](https://sheets.google.com)**
2. Click **+ Blank**
3. Name it: **GAK Calendar Bookings**

### Step 2: Import First File (1 min)
1. **File > Import > Upload**
2. Upload `1_Bookings.csv`
3. Import location: **Replace current sheet**
4. Click **Import data**
5. Rename "Sheet1" to **Bookings**

### Step 3: Import Remaining Files (2 min)
Repeat for each file:
1. Click **+** (add new sheet)
2. Name it: **Locations** (or Program_Types, or Users)
3. **File > Import > Upload**
4. Select the CSV
5. Import location: **Replace current sheet**
6. Click **Import data**

### Step 4: Update Emails (1 min)
1. Go to **Users** sheet
2. Replace demo emails with real emails:
   - mimi@gabrielsartkids.com → [Mimi's real email]
   - amanda@gabrielsartkids.com → [Amanda's real email]
   - etc.

### Step 5: Save Spreadsheet ID
1. Look at the URL:
   ```
   docs.google.com/spreadsheets/d/YOUR_ID_HERE/edit
   ```
2. Copy the ID (you'll need it later!)

## ✅ You're Done!

Your sheets should now have:
- **Bookings** - 11 sample bookings
- **Locations** - 2 locations with rooms
- **Program_Types** - 5 program types
- **Users** - Your staff members
